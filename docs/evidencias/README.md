# Evidências de execução

Os arquivos PNG desta pasta são relatórios renderizados a partir de saídas
reais de comandos executados em 14/10/2026. Os arquivos TXT contêm os comandos,
resultados e códigos de saída usados para produzir as imagens.

Não são screenshots nativos do terminal. A captura nativa solicitada no
critério do curso ainda precisa ser acrescentada.

A demonstração de geração verifica tamanho, alfabeto e presença das categorias
em memória; a senha é omitida antes de salvar os arquivos. Nenhuma senha de
uso real é exposta. A ajuda retorna 0, a validação de tamanho inválido retorna
2, e a análise estática e os 61 testes aprovados retornam 0.

As imagens complementam as execuções reproduzíveis com make lint e make test.
